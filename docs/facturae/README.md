# Esquema Facturae 3.2.2

`xsd/Facturaev3_2_2.xsd` y `xsd/xmldsig-core-schema.xsd` son los esquemas oficiales publicados en
facturae.gob.es (copiados del módulo l10n_es_facturae de OCA, que los distribuye sin cambios).
Los tests validan contra ellos el XML que genera `src/lib/facturacion/facturae.ts`.
